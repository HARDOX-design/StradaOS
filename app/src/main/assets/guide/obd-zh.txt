# StradaOS · OBD-II 诊断仪指南 · 中文。格式：见 ObdGuide.java。

== comprar | 买哪种诊断仪 | 能用的和要避开的
StradaOS 支持 ELM327 诊断仪，这是最常见、最便宜的一种。可通过蓝牙或 Wi-Fi 连接。
### 能用
- “经典”蓝牙（也标为 SPP、蓝牙 2.0 或 3.0）或双模。推荐：Vgate iCar Pro（蓝牙 3.0 版）、Veepeak Mini Bluetooth、OBDLink LX 和 OBDLink MX+。
- Wi-Fi：也能用，但屏幕连接诊断仪的网络时就没有互联网（在线地图、天气、AI）。
### 避开
- 只支持 BLE 的（Bluetooth Low Energy、“蓝牙 4.0”或“仅限 iPhone”），例如 OBDLink CX：Android 不会把它当作诊断仪，无法连接。
- 标着“v2.1”的超便宜仿制品：很多响应很差或不完整。如果你已经有一个，可以试试，有时能用。
提示：在包装或商品描述里找“Android”和“蓝牙 3.0”或“SPP”。如果只写“iOS”或“BLE”，就用不了。

== conector | 插在哪里、怎么配对 | OBD 接口和第一次连接
### 接口
它有 16 针，呈梯形。几乎总在驾驶座一侧的仪表台下方，靠近膝盖或保险丝盒旁边，有时藏在小盖板后面。找不到的话，请查看车辆说明书。
### 配对
- 插上诊断仪，打开点火开关（或启动发动机）。诊断仪上的指示灯应该亮起。
- 蓝牙：在“连接”中点“搜索附近的蓝牙诊断仪”，然后选中它。如需配对码，几乎都是 1234 或 0000。
- Wi-Fi：让屏幕连接诊断仪的 Wi-Fi 网络，输入它的 IP 和端口（通常是 192.168.0.10:35000）。
- 完成：连接状态应显示“实时”。
### 连不上时
- 有些车机的蓝牙只用于手机（免提），Android 看不到它。这类屏幕请使用 Wi-Fi 诊断仪。
- 在“连接”→“连接日志”里可以看到诊断仪的回应。
提示：如果车要停放好几天，请拔下诊断仪：有些即使熄火也会耗电瓶。

== panel | 车辆面板 | 每个仪表和颜色的含义
面板从驾驶座一侧滑出：用边缘的拉片、栏上的按钮或在“设置”中打开。它可以显示在任何主题之上。
### 三个仪表
- 冷却液：发动机温度。热车时 80 到 100 °C 属于正常。
- 电瓶：发动机运转时应在 13.5 到 14.8 V 之间（发电机在充电）。熄火时约 12.6 V。
- 转速：发动机每分钟转数（RPM）。
### 颜色
- 绿色：正常。
- 琥珀色：提醒。有项目超出正常范围，请留意。
- 红色：警报。请尽快处理；如果是冷却液，请在安全的地方停车。
下方有三项小数据（例如车速、发动机负荷或燃油）：点一下可查看图表。再往下是当前警报和故障码。

== alertas | 警报及其阈值 | StradaOS 何时提醒以及如何修改
开车时 StradaOS 会监测数据，并在屏幕上和用语音提醒你，即使你正在用 Waze 或听音乐。
- 提醒（琥珀色）：有项目超出正常范围，例如冷却液超过 100 °C。
- 警报（红色）：需要立即处理，例如冷却液超过 106 °C 或电瓶不充电。如果已开启，面板会自动打开。
- 冷却液温度上升过快、出现新的故障码时，也会提醒。
### 修改阈值
在“警报”→“各项数据何时报警”中，点一项数据即可开启或关闭监测，并修改提醒值和警报值。“出厂值”可以恢复原样。
出厂值适合大多数车辆。只有在你很了解自己的车时才修改（例如发动机平时就运行得比较热）。
>> obd_alerts | 前往“警报”

== codigos | 故障码 | 含义以及何时清除
发动机电脑检测到故障时，会保存一个故障码，例如 P0301。字母表示系统：P 发动机和变速箱，B 车身，C 底盘，U 通信。
- 待定：故障出现过一次；再次出现就会确认。
- 已确认：故障重复出现，可能会点亮发动机故障灯。
点一个故障码，可查看它的含义、严重程度和处理方法。
### 何时清除
- 只在修好故障之后，或为了看看它会不会再出现。
- 先记下故障码：修理厂要靠它来诊断。
- 在发动机熄火、点火开关打开时清除。
- 清除不等于修好：如果故障还在，故障码会再出现。
- 清除后，排放监测项目会有几天显示“未就绪”。这是正常的，但不要刚清除就去做尾气检测。
>> obd_codes | 前往“故障码”

== datos | 实时数据和图表 | 你的车能提供的所有数据
在“实时数据”里可以看到车辆提供的每一项数据：车速、发动机负荷、油门、进气温度、燃油、混合比等。每辆车提供的数据不同：某项没有出现，说明你的车不提供。
- 点一项数据即可打开它的图表。
- 图表最多可同时显示 3 项数据，时间范围 1 到 30 分钟。
- 标为“计算值”的数据由 StradaOS 根据其他数据推算（例如油耗），只是近似值。
提示：如果发动机没有 MAF 传感器，请在“高级”中填写排量，油耗会更准确。
>> obd_live | 前往“实时数据”

== ia | 逐步开启 AI | 可选：针对你的车解释故障码
AI 是可选的：不开启，StradaOS 也能解释最常见的故障码。开启后，解释会针对你的车。你需要自己的密钥（API key），屏幕也要能上网。
### Groq（免费）
- 打开 console.groq.com，用 Google 账号或邮箱登录。不需要银行卡。
- 进入“API Keys”→“Create API Key”，起个名字并复制密钥（以 gsk_ 开头）。密钥只显示一次。
- 在 StradaOS 中：人工智能 → 服务商：Groq → API key：粘贴。
提示：最好在同一块屏幕的浏览器里操作，这样可以直接复制粘贴密钥。如果在手机上操作，就得仔细手动输入。
### Claude 或 OpenAI（付费）
- Claude：platform.claude.com → Settings → API keys。需先在 Billing 中购买额度。
- OpenAI：platform.openai.com → API keys。同样使用预付费额度。
- 在 StradaOS 中选择服务商，粘贴密钥；如有提示，再选择模型。
### 最后
- 填写“你的车辆（供 AI 使用）”：品牌、车型、年份、发动机和变速箱。这样回答更准确。
- 点“测试 AI”。有回应就完成了。
只会发送故障码、你填写的车辆信息和当时的发动机数据，绝不发送你的位置。每次查询由你的服务商计费（Groq 在额度内免费）。
>> obd_ai | 前往“人工智能”

== limites | 读不到的数据和模拟车辆 | OBD-II 的局限，以及没有诊断仪时如何试用
### OBD-II 不提供的
- 胎压：几乎没有车会通过标准 OBD-II 提供胎压。需要另外加装胎压传感器（TPMS）。
- 仪表盘里程、机油液位，以及 ABS、安全气囊、自动变速箱等模块，几乎都不在标准范围内。
- 很老的车和部分老款柴油车可能没有 OBD-II。
### 模拟车辆
还没有诊断仪？在“连接”中选择“模拟车辆”，即可体验全部功能：仪表、语音警报、示例故障码和图表。几分钟内会出现一次测试用的过热和电瓶警报。它不会连接你的真车。
>> demo | 用模拟车辆试用
